# 3. Flux principal

Le parcours utilisateur commence par une autorisation, une creation ou une entree en position, puis se termine par un retrait, un reglement ou une mise a jour de dette. Les controles de limites, de permissions et de slippage se trouvent dans les contrats et doivent etre reproduits par le client. Les parametres sont toujours relus avant une transaction critique. Le depot source expose notamment Host, agreements CFA/IDA, Super Tokens, callbacks, realtime balance, solvency.
